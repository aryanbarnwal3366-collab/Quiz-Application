# Quiz Application

A simple Quiz Application developed using Python 3.

## Features
- Multiple Choice Questions
- Random Question Selection
- Input Validation
- Automatic Score Calculation
- Pass or Fail Result
- Answer Review

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Run this command:

py quiz.py
